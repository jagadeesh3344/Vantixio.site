# VANTIXIO — IDEAS INTO IMPACT

> A premium interactive technology and product studio digital experience built with React, TypeScript, Three.js, React Three Fiber, GSAP ScrollTrigger, and Lenis. Inspired by the spatial scrolling philosophy of [igloo.inc](https://www.igloo.inc/).

---

## 🚀 Quick Start

### 1. Installation
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The site will run locally at `http://localhost:3000`.

### 3. Production Build & Preview
```bash
npm run build
npm run preview
```

### 4. Type Check
```bash
npm run typecheck
```

## 🌌 Experience Architecture

- **Persistent Three.js WebGL World**: Single mounted Canvas hosting the shared volcanic fjord terrain, calm reflective water, and dynamic section artifacts.
- **Continuous 15-Screen Storyline**:
  - **Act I: The Spark & Philosophy (01–05)**: The Beginning (Glass Torus) → Our Philosophy (Aurora Ribbon) → What We Do (Service Monoliths) → What We Build (Hardware Showcase) → Our Process (Infinity Loop).
  - **Act II: The Engine & Proven Execution (06–10)**: Our Products (Product Monoliths) → Our Technology (3-Tier Chip Stack) → AI & Automation (Neural Brain) → UI/UX & Creative (Design Artboards) → Our Work (Case Studies & Metrics).
  - **Act III: Partnership, Reality & Cosmic Scale (11–15)**: The Vantixio Difference (Glass 'V' Totem) → About Vantixio (Studio Architecture) → Let's Create (Collaborative Studio) → The Next Step (Cosmic Summit over Earth) → Get in Touch & Master Footer (Hyderabad HQ).
- **Dual Conversion Actions**: Functional `Start a Project` multi-step interactive modal and `Schedule a Call` calendar drawer.
- **Universal Accessibility**: Semantic HTML5 DOM overlay for complete screen reader, SEO, and keyboard accessibility.
